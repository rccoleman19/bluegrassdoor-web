Visit review

This page is not in the site menu. It does not list visitors, and it does not show counts.

Visitor events are added to the Supabase table site_events on project bluegrassdoor. The public site can add a row. It cannot read one. Open the Supabase SQL editor for that project and run visit-queries.sql.

That file answers, for the last 30 days:

  • Top paths through the site
  • Pages with no page view
  • Clicks by control
  • Sections with no entry
  • Median time on a page, and the engage marks
  • Pages where a visit ends
  • Quote steps from a page view to a saved request
  • How often Dory is opened and then sent a message

An empty result means nobody has visited in that window yet. The table does not store a name, phone, email, address, or notes.
